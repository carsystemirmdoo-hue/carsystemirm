# Paint Takeover Brush Library

Isolated PRE-Phase 4 working library for Carsystem brush-reference assimilation.
Nothing in this directory is loaded by the approved
`/interaction-demo/paint-takeover-hybrid` route.

## Locked source boundaries

- `public/product-hero-patterns/spray-six-pass.svg` remains the quality,
  structure and full-composition reference only. Its six passes are not copied
  into the runtime proof.
- `public/product-hero-patterns/jedna linija.svg` remains untouched. A cleaned,
  `currentColor`-based structural copy is stored as
  `direct-shapes/carsystem-isolated-pass-clean.svg`.
- `public/art/paint-takeover/paint-takeover-hero-strokes.svg` remains the
  approved final 32-group hero asset and is not regenerated by the reference
  proof script.

## Selected internal assets

### Direct shapes

- `carsystem-isolated-pass-clean.svg` — primary Carsystem model, separated into
  `core`, `bristles`, `fragments`, `overspray` and `release`.
- `brush-broad-01.svg` — compact broad contact/core/edge reference.
- `brush-broad-02.svg` — curved pressure and broken-terminal reference.
- `curved-sweep-01.svg` — curved core and curve-following release reference.

### Reusable masks

- `dry-brush-01.svg` — long horizontal fragment waves.
- `dry-brush-02.svg` — diagonal dry release and detached fragments.

### Bristles

- `bristle-overlay-01.svg` — long/short bristle and fragment overlay.

### Spray

- `spray-drag-01.svg` — directional core, near overspray, far particles and end
  accent.
- `spray-burst-01.svg` — radial density reference for later burst groups.

### Splatter

- `splatter-01.svg` — sparse core/medium/fine particle source.

## Deliberately excluded from the selected library

- `brush-svg-reference-sheet.svg` — useful catalogue, but duplicates all source
  geometry and is not suitable for direct runtime placement.
- `scratch-01.svg` — structurally clean, but too technical for the six selected
  painterly proof groups.
- `thin-flick-01.svg` — very cheap and browser-safe, but intentionally retains a
  clean line language that is not part of this de-vectorization test.
- `drip-01.svg` — high-quality isolated accent, but its vertical gravity
  direction does not belong to the selected six groups.

## Six-group proof mapping

| Existing group | Role | Primary source | Nested proof parts |
|---|---|---|---|
| `hero-stroke-01` | Magenta left-entry broad | Carsystem isolated pass | contact, core, bristles, fragments, near/far overspray, release |
| `hero-stroke-02` | Blue/indigo right counter | `brush-broad-01.svg` | contact, core, bristles, fragments, near/far overspray, release |
| `hero-stroke-03` | Cream curved top sweep | `curved-sweep-01.svg` | contact, curve-masked core, bristles, fragments, near/far overspray, release |
| `hero-stroke-04` | Red/violet bottom sweep | `brush-broad-02.svg` | contact, core, bristles, fragments, near/far overspray, release |
| `hero-stroke-07` | Burgundy dry-brush field | `dry-brush-01.svg` | contact, fragments, fine bristles, detached fragments, release |
| `hero-stroke-12` | Cyan spray drag | `spray-drag-01.svg` | contact, core, bristles, fragments, near/far particles, end release |

The main body of every adapted group is revealed by a normalized
`stroke-dashoffset` mask following the stroke path. Secondary detail groups are
staged after the core. Reverse playback uses the same 0–1 state in reverse, so
it does not introduce a second transform or reveal system.
