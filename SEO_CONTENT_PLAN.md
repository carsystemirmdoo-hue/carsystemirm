# SEO Content Plan — Carsystem i R-M

## 1. SEO Goal

Build Serbian organic visibility around automotive refinish, auto boje, lakovi, poliranje, oprema za lakirnice, partner stores and professional brands.

The site should not rely only on homepage SEO. It should have a scalable structure for brand, category, location and educational pages.

## 2. URL Architecture

Recommended structure:

```txt
/
/katalog
/katalog/[kategorija]
/proizvodi/[proizvod]
/brendovi
/brendovi/[brend]
/partneri
/partneri/[grad]
/partneri/prodavnica/[slug]
/tehnicka-podrska
/edukacija
/edukacija/[clanak]
/kontakt
```

## 3. Brand Pages

Create pages for important brands only when there is enough useful content.

Potential pages:

- `/brendovi/rm`
- `/brendovi/carsystem`
- `/brendovi/baslac`
- `/brendovi/sata`
- `/brendovi/rupes`
- `/brendovi/cosmos-spray`

Each brand page should contain:

- intro,
- product categories,
- technical usage context,
- catalog links,
- partner locator CTA,
- inquiry CTA.

## 4. Category Pages

Potential categories:

- auto boje,
- lakovi,
- prajmeri,
- gitovi,
- abrazivi,
- poliranje,
- zaštitna oprema,
- alati i oprema,
- sprejevi,
- potrošni materijal.

Each category page should contain:

- explanation for end customers,
- professional notes,
- filters/products,
- recommended brands,
- partner locator CTA,
- FAQ.

## 5. Location Pages

Location pages can support searches like “auto boje Novi Sad” or “prodavnica auto boja Beograd”.

Possible structure:

- `/partneri/beograd`
- `/partneri/novi-sad`
- `/partneri/nis`
- `/partneri/kragujevac`
- `/partneri/subotica`

Only create location pages where real partner data exists. Do not create thin/empty SEO pages.

## 6. Education / Blog Topics

1. Kako izabrati pravi lak za automobil?
2. Razlika između baze i završnog laka.
3. Šta je prajmer i kada se koristi?

5. Kako pravilno koristiti abrazive u pripremi?
6. Osnove poliranja automobila.
7. Kada se koristi git, a kada prajmer?
8. Kako čitati tehnički list proizvoda?
9. Šta znači profesionalni refinish sistem?
10. Kako pronaći najbližu prodavnicu auto boja?

## 7. On-Page SEO Rules

- Serbian latinica.
- Clear H1 per page.
- Logical H2/H3 structure.
- Meta title and description.
- Internal links to catalog and partner locator.
- FAQ where useful.
- Product/category schema later if appropriate.
- Avoid duplicate thin content.

## 8. Internal Linking Strategy

Homepage links to:

- katalog,
- partner locator,
- key brands,
- technical support,
- partner page.

Category pages link to:

- related brands,
- related categories,
- educational articles,
- nearest store CTA.

Brand pages link to:

- relevant categories,
- products,
- articles,
- inquiry/partner locator.

## 9. Open SEO Decisions

- Exact brand/legal wording.
- Exact category taxonomy.
- Whether all products get indexable pages.
- Whether out-of-stock/inactive products remain indexable.
- How much content is realistic to write in first launch.
