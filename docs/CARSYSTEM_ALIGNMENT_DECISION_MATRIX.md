# Carsystem alignment decision matrix

**Decision:** pursue a controlled hybrid, not a direct Carsystem.org copy.

**Companion audit:** `docs/CARSYSTEM_ORG_COMPARATIVE_AUDIT.md`

**Priority:** P0 = launch/trust blocker; P1 = next strategic milestone; P2 = important follow-up; P3 = optional/later.

## Classification rules

- **COPY CLOSELY** — approved, brand-critical material or an objectively effective technical pattern; localise only what is required.
- **ADAPT** — retain the underlying idea, redesign it for Serbia, multi-brand use, accessibility, and performance.
- **KEEP OUR VERSION** — the current local solution is materially stronger; polish it without replacing its model.
- **REPLACE BOTH** — neither implementation adequately serves the target platform.
- **DO NOT COPY** — the official pattern is outdated, inaccessible, unsuitable, or creates unnecessary operational risk.

Every row below states the reason, user/business benefits, design/technical impact, complexity, dependency, risk, and exact implementation surface. No row authorizes implementation; this is a strategy artifact.

## Recommended execution boundary

The first implementation slice should not be a full redesign or backend build. It should prove the controlled hybrid visibly and safely:

1. approve identity/contact/claims and real imagery;
2. correct P0 trust/SEO issues;
3. create a light-first header + hero + professional category entry;
4. build one exemplary Carsystem product page with verified variant rows and documents;
5. measure performance/accessibility before extending the pattern.

This slice gives the owner an unmistakable alignment result while preserving the strongest existing work and avoiding an expensive, risky clone.
