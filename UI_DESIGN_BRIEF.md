# UI Design Brief — Carsystem i R-M

## 1. Desired Impression

The first impression should be:

> This is a serious, modern, high-tech automotive refinish distributor with strong brands, technical support and a real partner network in Serbia.

The design must not feel cheap, generic or like a basic product list.

## 2. Visual Keywords

- premium
- high-tech
- automotive
- precise
- refinish
- glass/gloss
- technical
- clean
- powerful
- trustworthy

## 3. Theme Direction

Support both dark and light theme if practical.

Recommended initial direction:

- dark premium hero,
- high-contrast product/brand cards,
- light sections for readability where needed,
- theme toggle later.

## 4. Color Direction

Use a restrained palette inspired by Carsystem and R-M identity.

Do not overuse brand colors. Use them as accents for:

- CTA,
- active states,
- line/glow details,
- section highlights,
- process indicators.

## 5. Hero Experience

The hero should suggest a refinish process:

- car bumper or painted panel,
- preparation → coating → gloss → final finish,
- subtle phase/timeline UI,
- future scroll-trigger animation readiness.

The first version may use static layered composition or mock 3D cards. Avoid overbuilding technical animation before the design is approved.

## 6. Key Components

### Floating Partner Locator

- persistent but subtle,
- premium card style,
- location icon,
- CTA text: “Pronađite najbližu prodavnicu”,
- manual fallback: “Izaberi grad”.

### Brand Strip

- elegant, monochrome or restrained,
- not too busy,
- can use placeholder logo chips.

### Catalog Preview Cards

- category cards,
- product count placeholder,
- brand tags,
- CTA: “Pošalji upit” / “Pogledaj katalog”.

### Technical Support Cards

- mikseri boja,
- komercijalisti,
- podrška lakirnicama,
- rešavanje problema.

### B2B Preview

- mini dashboard visual,
- private prices,
- rabati,
- upiti,
- assigned sales rep.

## 7. Homepage Section Order

1. Hero
2. Partner locator module
3. Brand ecosystem
4. Catalog preview
5. Why Carsystem i R-M
6. Partner network
7. Technical support
8. B2B login preview
9. Contact/location
10. Footer

## 8. Motion Direction

Use motion to support meaning, not to distract.

Good motion:

- scroll reveal,
- subtle hover states,
- hero phase progression,
- product card lift,
- locator card entrance,
- dashboard preview counters.

Avoid:

- constant distracting movement,
- heavy 3D on mobile,
- animation that delays content,
- motion with no reduced-motion fallback.

## 9. Mobile Rules

Mobile must be excellent.

- Partner locator CTA should be thumb-friendly.
- Hero must not depend on desktop-only animation.
- Sections should stack cleanly.
- CTAs should be visible early.
- Cards must not overflow.
- Typography must stay readable.

## 10. Copy Direction

Use Serbian latinica.

Possible headline directions:

- Profesionalni refinish sistem za Srbiju.
- Boje, oprema i podrška za savršen završni sloj.
- Povezujemo kupce, prodavnice i profesionalne refinish brendove.
- Pronađite najbližu prodavnicu iz naše partnerske mreže.

CTA labels:

- Pronađite najbližu prodavnicu
- Pogledaj katalog
- Pošalji upit
- Postani partner
- Kontaktiraj veleprodaju
- Prijava za B2B kupce
